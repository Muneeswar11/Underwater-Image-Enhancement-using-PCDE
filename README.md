# Underwater-Image-Enhancement-using-PCDE
This project focuses on enhancing underwater images using the PCDE (Piecewise Color Correction and Dual Prior Optimized Contrast Enhancement) technique. PCDE corrects color distortions and improves contrast to restore natural underwater scenes. The method achieved 74.65% improvement in Absolute Gradient (AG) and 34.13% increase in UIQM, outperforming HLPR and IBLA approaches, validated by visual and metric-based assessments.

Requirements:
1.MATLAB (with Image Processing Toolbox)
2.C Programming Environment

Pre-requisite:
1.Basic image processing knowledge
2.Familiarity with MATLAB and C programming
3.Understanding of color spaces and quality metrics (AG, UIQM)
